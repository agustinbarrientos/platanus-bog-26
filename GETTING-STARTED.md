## Deploying and integrations

Deployment platforms can only connect to repositories you own. They cannot be granted access to this organization repository. To deploy while keeping commits in both repositories, mirror the code to a personal repository:

1. Create a personal repository on GitHub.
2. Configure `origin` with both push targets:

   ```bash
   git remote set-url --add --push origin https://github.com/platanus-hack/platanus-hack-26-co-team-37.git
   git remote set-url --add --push origin https://github.com/<your-user>/<your-repo>.git
   ```

3. Connect the deployment service to the personal repository.

Future pushes will update both repositories while deployment runs from the repository you control.
